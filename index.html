The story

A farmer needs to cross a river with a wolf, a goat, and a cabbage. The boat is tiny: only the farmer and one other thing fit. Worse, the farmer must row every trip — nothing can cross alone.

Crossing rules

  • Farmer rows every trip — the boat never moves without the farmer aboard.
  • One cargo item per crossing — each trip is the farmer alone, or the farmer plus the wolf, goat, or cabbage. Never two at once.

Valid loads: farmer only, farmer + wolf, farmer + goat, or farmer + cabbage.

Safety rules

Computing recap

This puzzle is a classic planning problem. At any moment you have a state: who is on each bank and where the boat is. Each crossing is a move to a new state.

  • Constraints — crossing rules limit which moves exist; safety rules mark some states as failures.
  • State space — only finitely many arrangements matter (roughly a few dozen valid snapshots).
  • Search — a computer can try moves (or use breadth-first search) to find the shortest safe sequence; here the minimum is 7 crossings.
Think of each safe arrangement as a node in a graph; legal crossings are edges. Finding a path from “everyone on the start bank” to “everyone on the far bank” is the same kind of problem as route-finding in maps or AI planners.
